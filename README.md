# PlayWorks Snake

A fixed-HD arcade Snake game built with custom canvas rendering and Google IMA video ad flow.

## Tech Stack

- Vanilla JavaScript
- HTML Canvas API
- Vite
- Google IMA HTML5 SDK

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Controls

- Arrow keys - Move / Navigate
- Enter - OK
- Backspace - Cancel

## Notes

- All visible game UI is custom-rendered on canvas.
- DOM is used only for the canvas container and technical ads container.
- The game uses a fixed HD design: 1280x720.
- No external UI/game frameworks are used.
